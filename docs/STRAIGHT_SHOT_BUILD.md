# Straight-shot build

Keep main unchanged. iPhone first; solid cards, no frosted glass, waveform or word timing. This batch adds provider selection (offline, Gemini, OpenAI, Claude, OpenRouter, HTTPS compatible endpoint), device Keychain, searchable/reopenable history, original curated starter feed and macOS inbox target (Intel and Apple Silicon). Provider model IDs are configurable; no claim of live API success or free unlimited access. Cloud failure is explicit; choose offline manually. Local models require an HTTPS endpoint/tunnel. Discover is bundled starter content, not a live API feed; links point to related public planning repos, no code copied. Desktop inbox reads receiver files; receiver process still runs separately. Existing LAN protocol uses development pairing and plaintext HTTP; do not expose it to untrusted networks. Production secure pairing, transport, queue retry correctness, live feed, real-device testing, signing/TestFlight and visual fidelity review remain gates. No automatic execution of handoffs.
